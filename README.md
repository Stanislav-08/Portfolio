# Personal Portfolio Website

A fast, zero-dependency static portfolio built with HTML5, CSS3, and Vanilla JavaScript, configured for instant deployment on Vercel.

## Files Included
- `index.html` — Page structure and content (Hero, About, Projects, Skills, Contact)
- `style.css` — Responsive dark-mode styling
- `script.js` — Dynamic footer year and contact form `mailto:` handler
- `vercel.json` — Clean URL configuration for Vercel hosting

## Customization
1. Open `index.html` and replace placeholder names, project descriptions, GitHub links, and email addresses (`hello@example.com` in both `index.html` and `script.js`).
2. Adjust accent colors at the top of `style.css` under `:root`.
